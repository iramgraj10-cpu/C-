# ADR 0006: Dominio basado en evidencia calificada automáticamente

**Estado:** aceptada

## Contexto
Una barra de porcentaje de lecciones vistas no dice si la persona sabe programar.

## Decisión
Niveles: no iniciado, visto, practicado, dominado provisionalmente y retenido. El dominio provisional exige precisión mínima en una ventana de intentos calificados automáticamente, al menos 3 ítems distintos, código independiente sin solución vista y transferencia. «Retenido» exige además un repaso correcto tras un intervalo. Fallar una evaluación degrada la habilidad y programa un repaso inmediato. Las autoevaluaciones no cuentan. Los umbrales se ajustan en Ajustes y se validan.

## Consecuencias
- El panel de Progreso separa contenido visto, practicado, dominado y retenido, hábitos, errores recurrentes y calibración de confianza.
